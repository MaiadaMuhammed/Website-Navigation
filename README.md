# 🌐 Responsive Website Navigation

A clean and modern responsive navigation bar built using **HTML, CSS, and JavaScript**.
This project demonstrates a simple, user-friendly navigation system that works smoothly across all devices.

---

## 🚀 Live Demo

🔗 https://maiadamuhammed.github.io/Website-Navigation/

---

## ✨ Features

* 📱 Fully responsive design (mobile & desktop)
* 🍔 Mobile menu toggle (hamburger menu)
* ⚡ Lightweight and fast performance
* 🎯 Clean and simple UI
* 🧩 Easy to reuse in any project

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox & Media Queries)
* JavaScript (Vanilla JS)

---

## 📂 Project Structure

```
Website-Navigation/
│── index.html
│── style.css
│── script.js
```

---

## 💡 How It Works

* The navigation bar is displayed horizontally on larger screens.
* On smaller screens, it transforms into a hamburger menu.
* JavaScript is used to toggle the menu visibility.
* CSS media queries handle responsiveness.
* dark mode
*  Add active link highlighting
